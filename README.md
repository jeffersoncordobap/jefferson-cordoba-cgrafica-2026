# Proyecto
# Taller 2 - Formulario HTML5 y Estilos CSS

Este repositorio contiene la solución práctica para el **Taller 2**, donde se abordan conceptos de maqueta semántica en HTML5, posicionamiento, uso de variables en CSS y resolución de ejercicios prácticos.

---

## Contenido del Taller

El desarrollo está organizado en dos partes principales siguiendo el flujo de trabajo en Git:

### Parte 1: Formulario Web Semántico con CSS (`Taller2-parte1-224034007`)
- Versión final del formulario, empleando etiquetas sintacticas de HTML y estilos CSS.

### Parte 2: Ejercicios Prácticos del Módulo 36 (`Taller2-parte2-224034007`)
- Selección y resolución de 5 ejercicios prácticos a partir de la guía.
- Cada ejercicio se encuentra desacoplado en su propio archivo `.html` y `.css` dentro del directorio `/ejercicios`.
